## 完整测试流程

### 步骤 1: 登录系统
1. 打开 DOOR 管理后台
2. 使用测试账号登录

### 步骤 2: 选择赛事
1. 进入「我的赛事」模块
2. 选择或创建一个测试赛事
3. 确保赛事状态为「报名中」或「待抽签」

### 步骤 3: 名单导入
1. 进入「名单导入」页面
2. 点击「上传名单」
3. 选择 `test-participants-2000.xlsx`
4. 等待文件上传完成

### 步骤 4: 字段映射
系统会自动识别Excel列与标准字段的映射关系，请检查以下映射：

| Excel 列 | 系统字段 | 状态 |
|----------|----------|------|
| 姓名 | name | ✅ 自动映射 |
| 身份证号 | id_number | ✅ 自动映射 |
| 性别 | gender | ✅ 自动映射 |
| 出生日期 | birthday | ✅ 自动映射 |
| 手机号 | phone | ✅ 自动映射 |
| 参赛项目 | event | ✅ 自动映射 |
| 服装尺码 | clothing_size | ✅ 自动映射 |
| 城市 | city | ✅ 自动映射 |
| 紧急联系人 | emergency_name | ✅ 自动映射 |
| 紧急联系人电话 | emergency_phone | ✅ 自动映射 |
| 邮箱 | email | ✅ 自动映射 |
| 证件类型 | id_type | ✅ 自动映射 |
| 国籍 | country | ✅ 自动映射 |
| 民族 | ethnicity | ✅ 自动映射 |

### 步骤 5: 数据清洗
1. 点击「开始清洗」
2. 等待系统完成以下清洗操作：
   - 去重检查（身份证号、手机号）
   - 数据格式验证
   - 姓名转拼音
   - 行政区划标准化
   - 成绩数据解析
3. 查看清洗报告，确认无重大错误
4. 预览前50条数据

### 步骤 6: 确认导入
1. 点击「确认导入」
2. 等待数据写入数据库（约10-30秒）
3. 查看导入结果统计

### 步骤 7: 验证导入结果
1. 进入「报名管理」
2. 检查记录数是否为 2000
3. 抽查几条记录查看字段完整性

### 步骤 8: 配置抽签（验收标准）
1. 进入「抽签管理」
2. 配置各项目抽签容量：
   - 全程马拉松：设置目标人数（如 500人）
   - 半程马拉松：设置目标人数（如 400人）
   - 健康跑：设置目标人数（如 200人）
   - 家庭跑：设置目标人数（如 100人）
3. 配置抽签比例（如 85% 中签率）
4. 配置成绩筛选规则（可选）
5. 配置出发区分配

### 步骤 9: 执行抽签
1. 点击「开始抽签」
2. 等待抽签算法执行（可能需要几分钟）
3. 查看抽签结果统计：
   - 总报名人数
   - 各项目中签人数
   - 未中签人数
   - 候补人数

### 步骤 10: 验证抽签结果
1. 查看中签名单
2. 验证中签率是否符合配置
3. 检查成绩筛选是否正确应用
4. 导出抽签结果

## 常见问题

### Q: 导入时出现重复数据警告
A: 测试数据已确保身份证号唯一，如遇重复警告请检查：
1. 是否已导入过相同数据
2. 是否需要先清空现有数据

### Q: 抽签时提示人数不足
A: 确保各项目目标人数总和不超过 2000，且不超过各项目实际报名人数

### Q: 成绩数据未正确识别
A: 检查成绩字段格式是否为 `HH:MM:SS`（如 `03:30:45`）
