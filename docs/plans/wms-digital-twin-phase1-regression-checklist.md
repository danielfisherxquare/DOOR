# WMS Digital Twin Phase 1 Regression Checklist

- 创建两个以上仓库，并分别维护不同的长、宽、高与楼层数，确认互不串仓。
- 在同一机构下创建货架模板和货架实例，确认不同仓库只看到各自的实例与库位。
- 在 3D 设计页创建存储区、通道、缓冲区或出入口区域，并确认可以同步到 `layout_json`。
- 批量生成库位并打印库位二维码，确认二维码唯一且能回查到正确库位。
- 创建箱体、料箱、圆桶三种货物规格模板，并确认对象创建后自动注册二维码实体。
- 通过批量入库创建旧 `org_inventory_units` 时，确认同步生成 twin `inventory_objects`，并保持一一映射。
- 在库位绑定页分别验证手工输入、扫码枪输入和浏览器摄像头扫码三种方式都能回填货物码或库位码。
- 扫描库位码加货物码完成绑定，确认旧 `org_inventory_units`、新 `inventory_objects`、`location_bindings`、`twin_events` 同步更新。
- 重复绑定、跨仓绑定、超尺寸绑定、锁定位绑定都必须被拒绝，并返回明确错误。
- 同一对象同时发起两个绑定请求时，只允许一个成功，另一个必须失败，且最终只保留一个有效绑定。
- 绑定或移位成功后，3D 查看页应自动高亮目标库位，并能从右侧列表定位到该库位。
- 旧库存总览、入库页、二维码打印页、盘点页、报表页仍能读取正确的仓库与库位数据。
- 在至少一个真实仓库样例下打开 3D 设计、3D 查看、库位绑定三个页面，确认页面加载、筛选、保存和跳转都正常。
