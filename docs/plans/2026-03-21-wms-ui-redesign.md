# DOOR 仓储管理模块前端重构设计方案 (WMS Agile Workbench)

## 1. 业务愿景与核心需求
结合前期沟通与业务现状，本次重构的核心目标是将 **“列表式管理”** 升级为 **“高密度敏捷工作台 (Agile Workbench)”**，并重点解决以下四个核心诉求：
1. **核心流转掌控**：强化“进出库”和“物品流转”的呈现，使作业流程在一个工作台中形成闭环，解决操作割裂问题。
2. **空间与位置映射**：高度强化“地点”与“位置”的可视化感知，快速定位物资。
3. **精准余量观测**：提供直观的库容余量预警与健康度观察指标。
4. **入库精准归类与混合管理**：赛事物资、办公物资和赞助商物资在现实中是混合存放的，因此系统不应在顶层强制物理隔离，而必须在**入库源头**进行强制细分打标，并在全局以“混合且可辨识”的方式进行统一管理。

---

## 2. 核心架构与页面布局 (Bento Grid)
页面将放弃传统左右分栏，采用现代化的 **Bento Grid (便当盒网格)** 布局。首屏无需滚动即可掌握全局：

### 2.1 全局控制栏 (Global Toolbar)
悬浮在工作台最上方：
*   **多维过滤器 (Filters)**：默认展示全仓所有混合物资。提供 [物资类型]、[物资状态] 的下拉多选过滤，用于在庞大的混合库存中快速锁定目标。
*   **流转条形码/快捷查找 (SearchBar)**：支持快速扫描任何批次号、物资码或库位码。

---

## 3. 便当盒核心模块设计 (Modules)

### 3.1 模块 A：实时流转中心 (Workflow & Timeline) - 解决“进出库与流转”
占据页面左侧核心位置，分为上下两部分：
*   **快捷流转台 (Quick Actions)**：
    *   `[➕ 精细化入库]`：核心交互变革。点击后弹出的入库表单中，**强制要求对物资进行“打标/细分”**（选择：赛事物资、办公物资、赞助商物资），确保源头数据清晰。
    *   `[➖ 扫码出库]`、`[🔄 库内调拨]`：点击直接弹层处理，不跳转页面。
*   **实时流转日志瀑布流 (Live Feed)**：以 Timeline 形式实时滚动所有物料的最新动向。
    *   *示例图景*：🟢 `[入库]` 10:45 张三 将 50件 [赞助商]纯净水 (源头已打标) 放入 `A-1-2`。
    *   *示例图景*：🔴 `[出库]` 10:48 李四 将 2台 [办公]打印机 从 `B-3-1` 提走。

### 3.2 模块 B：可视化空间矩阵 (Space Visualizer) - 解决“地点与被混合的物资”
占据页面中部的视觉重心：
*   **2.5D 热力库位图**：使用高密度的方块矩阵图 (Matrix) 呈现二维平面的仓库缩略图。每个方块代表一个具体货架/库区。
*   **混合分布色谱**：由于三种物资是混合存放的，方块的颜色可以由该库位内“占比最高”的物资类型决定（例如赛事蓝、办公绿、赞助金），或者通过悬停浮窗展示该库位内三种物资的混合比例拼图。
*   **分类高亮 (Highlighting)**：当在全局过滤器中勾选“赞助商物资”时，包含赞助商物资的库位会高亮发光，其他库位变暗，瞬间从混合货架中找出目标。

### 3.3 模块 C：精准余量观察窗 (Capacity insights) - 解决“余量观察”
占据页面右侧数据区：
*   **红线预警雷达 (Alerts)**：直接罗列当前【储量低于安全线】、【库期超过 180 天呆滞】的物资。支持一键发起采购申请或报废。
*   **实时余量水位图 (Liquid/Bar Charts)**：用生动的“水位球”或带阈值的进度条展示三大类物资的【当前在库量 / 最大容量】比例。
*   **热门流转排行 (Top Movers)**：显示本周进出库最频繁的 Top 5 物品，方便管理者将其移至靠近出入口的黄金库位以提升效率。

---

## 4. 技术栈栈与视觉风格
*   **UI 框架与动效**：维持基于 React 的开发。引入 `Framer Motion` 实现 Bento Grid 模块加载和切换时的顺滑阻尼动效。
*   **图表与数据看板**：引入 `Echarts-for-React` 处理趋势图及空间热力矩阵 (`Heatmap` 图表非常适合做 2.5D 的库位占用图)。
*   **视觉规范**：Dark Mode 或高对比度的深色玻璃态主题，配合“赛事蓝”、“赞助金”、“办公绿”三种主题色标记不同物资，强化视觉直觉。

---

## 5. 后续演进计划
如果未来由于仓库变大需要完全的 3D 呈现空间关系，可将此时的“模块 B（空间矩阵）”平滑升级为基于 `react-three-fiber` 的纯 3D 画布，原有业务流转逻辑和数据接口保持不变。
